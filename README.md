# K-TECHNIK | Premium Security Šumperk 🔐

Moderní, vysoce výkonná webová prezentace pro tradiční šumperské zámečnictví a bezpečnostní centrum založené v roce 1998. Projekt je postaven na principech **Bento Grid designu** a minimalistické architektury.

## 💎 Vizuální Koncept
Web využívá estetiku **"Space Black & Electric Blue"**, která kombinuje hluboké tmavé tóny s neonově modrými akcenty. Cílem bylo vytvořit pocit nekompromisního bezpečí a technologické vyspělosti.

### Klíčové funkce:
- **Glassmorphic Navigation:** Fixní menu s efektem rozostřeného skla pro moderní UI.
- **Bento Grid Services:** Strukturované zobrazení služeb inspirované designovým jazykem Apple.
- **Dynamic Nonstop Status:** Interaktivní prvek v navigaci signalizující pohotovost s animací pulzujícího bodu.
- **Responsive Layout:** Plně optimalizováno pro všechna zařízení (Desktop, Tablet, Mobile).
- **Precizní Typografie:** Použití fontu *Inter* pro maximální čitelnost a technický dojem.

## 🛠️ Použité Technologie
- **HTML5:** Sémantická struktura pro lepší SEO.
- **CSS3 (Custom Properties):** Pokročilé využití proměnných pro snadnou údržbu barev a stylů.
- **Flexbox & Grid:** Moderní layoutové systémy pro precizní zarovnání prvků.
- **FontAwesome:** Integrace ikonografického systému pro intuitivní navigaci.
- **Google Maps API:** Integrovaná interaktivní mapa provozovny.
